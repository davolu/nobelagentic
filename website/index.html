Agents that get out of your way.

One line to start. Any model. Tools from a type hint. Python and TypeScript, same API.

pip install nobelagentic npm i nobelagentic Read the docs 
from nobelagentic import Agent, tool

@tool
def get_weather(city: str) -> str:
    """Current weather for a city."""
    ...

agent = Agent("You help plan trips",
              tools=[get_weather, "web"])
agent.run("Plan a 3-day trip to Lagos")

Complexity is opt-in, never required.

Most frameworks make you learn their graph, their crew, or their chain on day one. Here you start with one agent and reach for more structure only when you need it. All three levels run on the same kernel, so streaming, tracing and checkpoints behave identically everywhere.

researcher = Agent(
    "Find and summarize sources",
    tools=["web", "files"],
    mcp=["github"],
)
researcher.run("What changed in Python 3.14?")
# v0.3
crew = Crew(
    agents=[researcher, writer, editor],
    process="sequential",
    memory=True,
)
crew.run("Write a report on African fintech")
# v0.2
g = Graph(state=ReportState)
g.node("research", researcher)
g.node("write", writer)
g.edge("research", "write")
g.edge("write", lambda s: "research" if s.needs_more else END)
g.run(ReportState(topic="..."), checkpoint="run-42")

Tools from a type hint. Packs by name.

A function with type hints and a docstring is a tool. Built-in packs load lazily, declare what credentials they need, and stay out of the context window until you ask for them.

web

Search, fetch and clean pages, raw HTTP requests.

files

Read, write, list, regex-search — sandboxed to a root.

shell

Commands and in-process code. Opt-in only.

time

Now in any timezone, date math, conversions.

math

Safe expression evaluation and unit conversion.

data

JSON paths, CSV in and out, quick column stats.

Any MCP server is a tool pack.

Name a server and its tools appear next to your own, indistinguishable from native ones. A built-in registry covers GitHub, Postgres, Playwright, the filesystem and more; add your own with one command.

Agent(mcp=["github", "postgres"])

# or a remote server
Agent(mcp=["https://tools.example.com/mcp"])

# register one for every project
$ nobelagentic mcp add weather "npx -y weather-mcp"

One provider interface. Every model behind it.

Set an API key and the model is picked for you. Name a model and the provider is inferred from it. Swap vendors without touching your agent code.
